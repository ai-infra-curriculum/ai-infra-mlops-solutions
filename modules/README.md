# Module Solutions

Reference implementations for every exercise in
[`ai-infra-mlops-learning/lessons/`](https://github.com/ai-infra-curriculum/ai-infra-mlops-learning/tree/main/lessons).

Each module directory matches the learning repo's slug. Inside, one
subdirectory per exercise with a `README.md` linking back and the reference
implementation.

Many exercises in this track overlap topics covered in detail elsewhere in the
curriculum (notably `ai-infra-engineer-solutions/modules/mod-106-mlops`). Where
that's the case the exercise README links to the deeper engineer-solutions
exercise rather than duplicating content.

## Module index

- [01-mlops-foundations](01-mlops-foundations/) — assessment, pipeline design, anti-patterns, minimal stack, charter
- [02-experiment-tracking](02-experiment-tracking/) — MLflow tracking, registry, HPO, pyfunc, e2e
- [03-model-monitoring](03-model-monitoring/) — KS test, PSI, Evidently, alerts, full pipeline
- [04-data-quality](04-data-quality/) — Pydantic schema, Great Expectations, statistical checks, profiling
- [05-experimentation](05-experimentation/) — A/B framework, significance, bandits, progressive rollout
- [06-automation](06-automation/) — Airflow, Kubeflow, retries, MLflow integration, prod pipeline
- [07-governance](07-governance/) — fairness, bias mitigation, model cards, audit logging, framework
- [08-production-ops](08-production-ops/) — readiness, capacity, SLO/SLI, incident response
- [09-security](09-security/) — threat modeling, Vault, SLSA, container security
- [10-advanced-topics](10-advanced-topics/) — LLMOps (vLLM), RAG, edge ML, AutoML, real-time
